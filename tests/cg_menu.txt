# Code generation A/B run on the title menu (lockstep discs, scripts/compare_runs.py): the cursor sound
# three times, LOAD, the first slot loaded (tests/save.txt's save on the VMU) and idling in the game, which
# plays the load's jingle and the ambience. Nothing is masked: the stacks (dumped at 0x80072000) and
# libaudio's event nodes (0x80370000-0x8038FFFF) have to match too. The cursor sound once rang for good
# when a skipped register save left a stale stack word (config/quest64.us.toml, skip_saves).
